===============================================================================
                          存储的数据字段
===============================================================================

共12个字段，全部按照用户指定的需求存储：

字段名    类型      说明
-------- --------- --------------------------------------------------
e        TEXT      事件类型（"kline"）
E        INTEGER   事件时间（毫秒）
s        TEXT      交易对（如"BTCUSDT"）
t        INTEGER   K线开始时间（毫秒）
T        INTEGER   K线收盘时间（毫秒）
i        TEXT      时间间隔（"1m"、"5m"等）
o        REAL      开盘价（浮点数）
c        REAL      收盘价（浮点数）
h        REAL      最高价（浮点数）
l        REAL      最低价（浮点数）
v        REAL      基础资产成交量（浮点数）
q        REAL      计价资产成交量（浮点数）

所有数字字段均以REAL类型（float64）存储，确保精度。

===============================================================================
                          使用示例
===============================================================================

最小化示例：

    package main
    
    import (
        "context"
        "time"
        dfs "goQuant/internal/dataManager"
    )
    
    func main() {
        // 1. 创建处理器
        processor, _ := dfs.NewKlineProcessor("./data/klines.db")
        defer processor.Close()
        
        // 2. 订阅K线
        ctx, _ := context.WithTimeout(context.Background(), 1*time.Hour)
        ch, err, close := dfs.SubscribeKlines(ctx, "BTCUSDT", "1m", "")
        defer close()
        
        // 3. 处理流（自动保存）
        processor.ProcessStream(ctx, ch, err)
        
        // 4. 查询结果
        klines, _ := processor.QueryKlines("BTCUSDT", "1m", 10)
        for _, k := range klines {
            println(k.Symbol, k.ClosePrice)
        }
    }
